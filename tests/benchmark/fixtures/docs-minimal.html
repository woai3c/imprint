Installation

Clearline installs as a single binary. Package managers are supported for every major platform.

brew install clearline
clearline init my-project

Configuration

Configuration lives in clearline.toml at the project root. Sensible defaults mean most files stay under ten lines.

  • One file per project, checked into version control
  • Environment overrides with the CLEARLINE_ prefix
  • Schema validation on every run
Tip: run clearline doctor after upgrading.
The doctor command verifies that your config schema matches the installed version.

First run

The first run builds a local cache. Subsequent runs reuse it and typically finish in under a second.
