# Public showcase constraints

- This is a local, static, reproducible showcase. Do not deploy or publish it.
- Read `DESIGN.md` and `TASK.md` before implementation.
- Treat `DESIGN.md`, `variables.css`, `theme.css`, and `TASK.md` as immutable inputs.
- Implement only `index.html`, `styles.css`, and `app.js`.
- Load `variables.css` globally and reuse its exported tokens instead of inventing an unrelated palette or spacing scale.
- Do not copy Astro names, logos, text, illustrations, images, or page layouts.
- Do not use remote assets, external dependencies, build tools, or network requests.
- Keep the result accessible, responsive, and usable through keyboard and pointer input.
